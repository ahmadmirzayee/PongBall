## Pong-Ball
A modern recreation of the classic Pong game with soccer theme built with Unity, featuring adaptive AI, local multiplayer, and power-ups.

## Features
- Single Player (Adaptive AI)
- Local Multiplayer
- Adaptive Difficulty
- Power-Ups
- High Score System
- Sound Effects & Music
- Settings Menu

## Controls
### Player 1
W / S → Move
### Player 2
Up Arrow / Down Arrow → Move

## Game Modes
### Player vs Player
Play against a friend locally.
### Player vs AI
Challenge an adaptive AI and achieve the highest score possible.

## Power-Ups
- Score Multiplier ×2
- Score Subtractor
- Shield

## Technologies
- Unity 6
- C#

## How to Run
1. Clone the repository.
2. Open the project with Unity.
3. Open the Main scene.
4. Press Play.
